# Activism Experiment — Data Analysis Pipeline

This directory contains the data processing, statistical analysis, and power simulation pipeline for the activism public goods experiment.

---

## Directory Structure

```text
analysis/
├── README.md                             # This documentation file
├── activism.Rproj                        # RStudio Project file (enables root-relative paths via here::here())
│
├── data/
│   ├── raw/                              # Immutable raw data inputs
│   │   ├── raw_s1_all_apps_wide_*.csv    # oTree session 1 wide export
│   │   ├── raw_s2_all_apps_wide_*.csv    # oTree session 2 wide export
│   │   ├── raw_s1_PageTimes-*.csv        # Session 1 page time logs
│   │   ├── raw_s2_PageTimes-*.csv        # Session 2 page time logs
│   │   ├── data-overview.csv             # Session summary overview
│   │   ├── Questionnaire.xlsx            # Post-experimental survey & demographics (Session1 & Session2)
│   │   └── spreadsheets/                 # Original Apple Numbers spreadsheets (archival)
│   │       ├── s1.numbers, s2.numbers
│   │       └── s1-pagetimes.numbers, s2-pagetimes.numbers
│   │
│   └── processed/                        # Generated by 01_data_cleaning.Rmd (never edit manually)
│       ├── clean_dfs.RData               # R binary containing df_wide, df_long, df_clean, df_participant
│       ├── df_long.csv                   # Main long panel dataset (merged with demographics)
│       └── df_wide.csv                   # Participant-level wide dataset (merged with demographics)
│
├── scripts/
│   ├── 01_data_cleaning.Rmd              # Step 1: Ingests raw data & questionnaire -> cleans -> exports to processed/
│   ├── 02_pilot_analysis.Rmd             # Step 2: Primary analysis notebook (descriptives, mixed models, figures)
│   └── power_analysis/
│       ├── power_analysis.py             # 4-arm power simulation (Python / statsmodels / CR2)

│
└── output/                               # Generated outputs & artifacts
    ├── figures/                          # Plot exports (.png, .pdf)

    └── reports/                          # Rendered HTML reports (e.g. 01_data_cleaning.html, 02_pilot_analysis.html)
```

## Workflow & Execution Order

### 1. Data Cleaning & Questionnaire Merging
Open and knit or run:
```r
rmarkdown::render("analysis/scripts/01_data_cleaning.Rmd", output_dir = "analysis/output/reports")
```
- Reads raw oTree CSVs and merges post-experimental demographics from `Questionnaire.xlsx` matching by `session` and `seat_number`.
- Creates `data/processed/clean_dfs.RData`, `df_long.csv`, and `df_wide.csv`.

### 2. Pilot Statistical Analysis
Open and knit or run:
```r
rmarkdown::render("analysis/scripts/02_pilot_analysis.Rmd", output_dir = "analysis/output/reports")
```
- Loads `data/processed/clean_dfs.RData`.
- Performs descriptive statistics, balance tests, non-parametric tests, mixed-effects regressions (lme4/lmerTest), and produces visualizations.

### 3. Power Analysis & Sample Size Sizing
Run the simulation via Python:
```bash
python3 analysis/scripts/power_analysis/power_analysis.py --nsim 1000 --analytic
```

## Best Practice Guidelines
- **Portability**: All file paths use `here::here()` anchored to the repository root. 
- **Data Immutability**: Files in `data/raw/` are treated as read-only.
- **RStudio Integration**: Always open `activism.Rproj` when working in RStudio to automatically initialize the working directory.
